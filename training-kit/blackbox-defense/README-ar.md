# حزمة BLACKBOX للتدريب الدفاعي المحلي

ملفات اصطناعية لأربعة تمارين: سجلات مصادقة، وسلامة إعدادات، وترويسات HTTPS، ورؤوس بريد. تنفّذ القراءة والمقارنة على جهازك باستخدام Python 3، وتوثّق ملاحظاتك داخل المسار المناسب في BLACKBOX.

## البدء

1. استخرج ZIP كاملًا، ثم افتح الطرفية داخل مجلد `blackbox-defense` الذي يحتوي `analyze.py`.
2. تحقق من تثبيت Python 3. في Linux/macOS استخدم `python3`؛ في Windows يمكنك استخدام `py -3` أو `python` حسب تثبيتك.
3. اقرأ الملف الأصلي وحدّد سؤال التحقيق، ثم استخدم القارئ للتحقق من ملاحظاتك. لا تحتاج مكتبات إضافية أو اتصالًا بالشبكة.

```sh
python3 analyze.py --help
python3 analyze.py logs
python3 analyze.py integrity
python3 analyze.py headers
python3 analyze.py email
```

أضف `--json` لإخراج منظم، مثل `python3 analyze.py logs --json > observations.json`. إعادة التوجيه تنشئ ملف المخرجات الذي اخترته؛ القارئ نفسه يقرأ ملفات الحزمة دون تعديلها أو تنفيذ محتواها. يعمل أيضًا من مجلد آخر لأنه يبحث عن الملفات بجوار السكربت.

## موجز المتعلم

| المسار | ملفات الأدلة | المطلوب تسليمه |
| --- | --- | --- |
| سجلات المصادقة | `auth-events.csv` | خط زمني يربط الجلسة بالمصدر والجهاز، ثم مذكرة فرز تفصل الوقائع عن الاستنتاجات. احسب عدد الأحداث والجلسات من الملف بنفسك. |
| سلامة الملفات | `integrity/baseline/` و`integrity/current/` ومرجع البصمة وسجل التغيير | جدول فروق الإعداد وأثرها، ثم إعادة تحقق بنسخة عمل دون تعديل ملفات الدليل الأصلية. |
| ترويسات الويب | `headers/before.txt` و`headers/after.txt` | جرد للترويسات وخصائص الجلسة، ومقارنة الضوابط، ومصفوفة تحقق تربط كل استنتاج بدليله وحدوده. |
| البريد | `email/suspicious.eml` و`email/legitimate.eml` | مقارنة هوية المرسل والرد ونتائج المصادقة، ثم بلاغ تدريبي محدد النطاق يذكر درجة الثقة والتثبت المطلوب. |

سياق البريد: الجهة التدريبية المتوقعة تستخدم نطاق `lab.example`، والبوابة الموثوقة داخل السيناريو هي `gateway.training.example`. تحديد هذا المصدر جزء من تفسير `Authentication-Results`؛ وجود الترويسة وحده في رسالة حقيقية لا يثبت موثوقيتها.

ملفا الويب يمثلان أصل HTTPS اصطناعيًا هو `https://portal.training.example/`. لا يجري القارئ أي اتصال به، ولا تكفي قراءة الملف لإثبات تطبيق المتصفح للضوابط أو سلامة الاتصال الفعلي.

## كيف تراجع عملك؟

نفّذ مراحل المسار بالتتابع: اقرأ الدليل، استخرج ملاحظاتك، ثم دوّن الاستنتاج والقرينة والحدود والخطوة التالية. مجرد تشغيل القارئ لا يؤكد الإنجاز. إذا احتجت مساعدة، افتح [التلميحات والمراجعة](REVIEW-ar.md): تبدأ بتلميحات عامة ثم تعرض مؤشرات العينات بعد المحاولة.

## سلامة النسخة وحدود الأداة

يسرد `SHA256SUMS` بصمات الملفات الموزعة. تطابق SHA-256 يثبت تطابق البايتات مع مرجع الحزمة فقط؛ لا يثبت أصالة مصدر مستقل أو خلو ملف من البرمجيات الخبيثة. احتفظ بالأصول كما هي، واستخدم نسخة عمل عند تجربة تعديل.

لا توجد كلمات مرور حقيقية أو مرفقات تنفيذية في العينات. روابط البريد معطّلة بصيغة `hxxps` ولا يلزم تحويلها أو فتحها. القارئ يستخدم مكتبات Python القياسية فقط، ويعيد رمز خروج غير صفري عند ملف مفقود أو صيغة غير صالحة. لا يفحص جهازك أو شبكتك ولا يتخذ قرار احتواء أو يمنح درجة موثقة.
