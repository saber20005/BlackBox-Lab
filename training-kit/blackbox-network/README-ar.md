# BLACKBOX — مختبر Nmap عملي على هدف HTTP معزول

هذه ورشة **تنفذها بنفسك** باستخدام Kali Linux وPython 3 وآلة هدف تدريبي
داخل VirtualBox على Windows. هي خدمة HTTP مصطنعة **غير مصممة للضعف أو
الاستغلال**؛ لا تتطلب حسابات أو بيانات حقيقية ولا تستخدم الإنترنت.

## 1. العزل أولًا

- أنشئ VM هدفًا تجريبيًا واحتفظ بلقطة Snapshot له.
- من إعدادات VirtualBox لكل من Kali والهدف، اختر Host-Only **فقط**
  للفحص، وأوقف NAT وBridged للمختبر. تحقق من كل محول بنفسك.
- داخل VM الهدف، اقرأ عنوان واجهة Host-Only باستخدام `ip -br addr`.
  لا تفترض أن `192.168.56.102` هو العنوان الموجود على جهازك.
- احصر اسم آلة الهدف وعنوانها والمنفذ 8088 في سجل نطاق التجربة؛
  لا تفحص الأجهزة الأخرى أو شبكة المنزل أو عنوانًا عامًا.

**مهم:** يتحقق السكربت من شكل العنوان الخاص ومن تأكيدك اليدوي فقط.
لا يستطيع إثبات أن المحول الحقيقي Host-Only؛ أنت مسؤول عن التأكد منه.

## 2. تشغيل الهدف (داخل VM الهدف)

انسخ هذا المجلد إلى آلة الهدف، ثم نفّذ مع **عنوان Host-Only الحقيقي للهدف**:

```sh
python3 target_service.py --bind 192.168.56.102 --port 8088 --confirm-host-only
```

سيظهر إشعار بأن الهدف يعمل. لإيقافه اضغط Ctrl+C.

للعمل على **آلة Kali نفسها دون شبكة** يمكن استعمال loopback فقط:

```sh
python3 target_service.py --bind 127.0.0.1 --port 8088
```

## 3. من Kali: التأكد ثم فحص آلة واحدة

استبدل `192.168.56.102` بعنوان VM الهدف الذي راجعته في الخطوة 1:

```sh
ip -br addr
ip route
curl --max-time 3 http://192.168.56.102:8088/health
nmap -Pn -sV --version-light -p 8088 -oN nmap-evidence.txt 192.168.56.102
```

إذا استخدمت حلقة loopback المحلية بدل VM منفصل، استبدل العنوان
بـ `127.0.0.1` في أوامر curl وNmap. لا تغيّر الخيارات إلى فحص شبكة
كاملة أو استكشاف عناوين مجهولة.

تأكد من وجود استجابة `/health`، ثم اقرأ حالة المنفذ 8088 في تقرير Nmap.
قد تختلف تسمية الخدمة حسب إصدار Nmap؛ لا تصفها بثغرة لمجرد أنها مفتوحة.

## 4. ملف التسليم

سجل الملاحظات مع أدلتها في مرحلة **Nmap — فحص المضيف المحدد**:
1. اسم VM الهدف وعنوانها ولقطة الإعداد وتأكيد Host-Only (دون أسرار).
2. الأمر الذي نفذته وتاريخ الفحص ووقت الاستجابة.
3. تقرير `nmap-evidence.txt` الذي أنشأته بنفسك وملخص منفذ 8088.
4. تفسير الفرق بين `open` و`closed` و`filtered` مع حدود الاستنتاج.
5. إجراء دفاعي واحد، وكيف تعيد التحقق منه بأمان.

**لا ترفع سجلات LAN حقيقية أو عناوين شخصية أو كلمات مرور.**
يمكن مراجعة التقرير محليًا، لكن الملف النصي قابل للتعديل أو الإنشاء دون
تشغيل Nmap؛ لهذا لا يعد وحده إثباتًا خادميًا لتنفيذ المهارة.

## 5. الإغلاق وإعادة الضبط

أوقف الهدف بـ Ctrl+C، وتحقق من إغلاق المنفذ، ثم أطفئ VM التدريب
واحتفظ باللقطة المرجعية. لا تُبقِ الهدف متصلًا بشبكة أخرى.

## الاختبارات الآلية للهدف

```sh
python3 -m unittest discover -s training-kit/blackbox-network -p 'test_*.py'
```

تعمل الاختبارات على `127.0.0.1` فقط وبمنفذ مؤقت، وتتحقق من منع
الربط بأي عنوان عام أو `0.0.0.0` ومن عدم عرض أي ملفات من الجهاز.

## متى يستحق شهادة؟

يلزم نتيجة تقييم خادمي مستقلة وسجل تنفيذ عملي موثوق يُراجع
على أساس سياسة إصدار معلنة. لا تكفي علامة الإكمال اليدوية أو ملف Nmap وحده؛
إصدار شهادات BLACKBOX الموثّقة ما زال معطّلًا.
