# BLACKBOX Lab

مساحة تدريب عربية مستقلة تعمل بملفات ثابتة: 6 مسارات و18 مرحلة، مع متابعة الخطوات والنتائج والملاحظات.

## التشغيل

شغّل أي خادم ملفات ثابتة من مجلد المشروع، مثل:

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

ثم افتح `http://127.0.0.1:4174/`. يستخدم التطبيق وحدات JavaScript، لذلك شغّله عبر HTTP بدل فتح الملف مباشرة. يمكن نشر الملفات كما هي على Vercel أو GitHub Pages؛ جميع مسارات الأصول نسبية.

## ما الذي يتضمنه؟

- لوحة تحكم تعرض المراحل المكتملة وبنود التحقق والمراحل الموثقة، مع زر متابعة آخر نشاط أو المرحلة التالية المتاحة.
- مكتبة مسارات قابلة للبحث والتصفية حسب التقدم، وفتح متتابع للمراحل.
- حفظ تلقائي لمسودات النتائج والملاحظات، بما يشمل التنقل وتغيير مربعات التحقق.
- سجل بتواريخ الحفظ والإنجاز الفعلية عند توفرها.
- نسخ JSON احتياطية ذات إصدار، مع فحص النسخة ومعاينة ملخصها قبل الاستعادة. يقبل التطبيق أيضًا النسخ القديمة التي صدّرها BLACKBOX.
- تقرير Markdown يشمل التقدم وقوائم التحقق والنتائج والملاحظات والتواريخ.
- صفحة مهارات تربط أفضل نتائج CyberTrace بحساب BLACKBOX، مع زيادة النقاط عند تحسّن النتيجة. راجع [دليل الربط](docs/cybertrace-skills.md).

## حفظ البيانات

تُحفظ بيانات الضيف في `localStorage` على المتصفح الحالي، تحت المفتاح `blackbox-progress-v1` للمحافظة على تقدم النسخة السابقة. تتوفر حسابات اختيارية بالبريد وكلمة المرور أو Google، مع مزامنة عبر مشروع Firebase المستقل `black-box-lab`. نقل تقدم الضيف إلى الحساب إجراء صريح من نافذة الحساب. راجع [إعداد الحسابات](docs/accounts-setup.md). نزّل نسخة احتياطية قبل مسح بيانات المتصفح أو الانتقال إلى جهاز آخر.

إذا تعذّر التخزين، يوضح التطبيق ذلك ويحافظ على العمل في ذاكرة التبويب، مع إمكانية تنزيل نسخة قبل إغلاقه. ملف الاستعادة لا يغيّر البيانات الحالية قبل اجتياز التحقق وتأكيد المستخدم ونجاح الحفظ. حد حجم الملف 5 MiB، وحد النص الواحد في النسخ المستوردة 100,000 محرف؛ تُحفظ النصوص القديمة الأطول دون اقتطاع، ويُبيّن التصدير إن كانت تحتاج تقليلًا لتلائم صيغة النسخ.

حالات الآلات والشبكة تُدخل يدويًا. الموقع يقدّم التعليمات والتوثيق، ولا يشغّل الأدوات أو يستشعر VirtualBox من المتصفح.

## روابط المشاركة والظهور في البحث

- رابط مسار: `https://blackboxlab.dev/?view=tracks&track=webgoat`.
- رابط مرحلة: `https://blackboxlab.dev/?track=recon&stage=0`؛ رقم المرحلة في الرابط يبدأ من الصفر.
- تتوفر أزرار لنسخ رابط المسار أو المرحلة دون معاملات الحملة. يبقى التنقل العادي محتفظًا بمعاملات UTM المعروفة، وتعمل أزرار الرجوع والتقدم وإعادة التحميل.
- لا تفتح الروابط المراحل المقفلة؛ تعرض المسار وسبب القفل مع بقاء التقدم كما هو. تُعاد الروابط غير الصالحة إلى صفحة معروفة.
- النطاق الأساسي هو `https://blackboxlab.dev/`. تتوفر بيانات Open Graph وTwitter وصورة مشاركة، و`robots.txt` و`sitemap.xml` للصفحات العامة الفعلية. صفحات السجل والنسخ والمراحل غير مخصصة للفهرسة؛ canonical المرحلة يشير إلى مسارها.
- تتضمن الصفحة رابطًا إلى CyberTrace، وروابط تحقيقات مرتبطة بمهارات الويب وتحليل الشبكات.

تُجهّز أحداث الاستخدام دون إرسال نصوص الملاحظات أو النتائج. تفعيل القياس المركزي يحتاج معرف GA4 حقيقيًا في وسم `google-analytics-id`؛ راجع [إعداد التحليلات](docs/analytics-setup.md). القيمة الفارغة لا تفعّل خدمة خارجية.

## بنية الملفات

- `index.html`: هيكل الصفحة والتنقل.
- `styles.css`: المظهر والتجاوب.
- `data.js`: محتوى المسارات والمراحل وحلول الأعطال.
- `app.js`: الواجهة والتدريب والتصدير والاستعادة.
- `progress.js`: التوافق مع البيانات السابقة والتحقق والحفظ.
- `routes.js`: تحليل الروابط والتحقق منها وعناوين الصفحات والروابط الأساسية.
- `analytics.js`: أحداث الاستخدام المسموح بها وربط القياس عند إعداده.
- `account-ui.js`: واجهة الحساب والدخول والاستعادة وحل تعارض المزامنة.
- `account-sync.js`: فصل الضيف والحسابات والتخزين المحلي وتنسيق المزامنة.
- `firebase-client.js` و`account-config.js`: اتصال Firebase الحقيقي وإعداد الخدمة العام.
- `firestore.rules`: قواعد المستند الخاص بكل مستخدم؛ راجع قواعد المشروع القائمة قبل نشرها.

## الاختبارات

```sh
node --test --test-isolation=none tests/*.test.mjs
```

تغطي اختبارات البيانات التوافق مع النسخة السابقة، واستدارة النسخ الاحتياطية، ورفض المدخلات غير الصالحة، وتعذّر التخزين.
وتغطي اختبارات الروابط القيم غير الصالحة والمراحل المعروفة وحفظ الحملة أثناء التنقل وروابط المشاركة النظيفة وcanonical الصفحات العامة.
تغطي اختبارات الحسابات عزل البيانات، وتعارض المراجعات، وأخطاء التخزين، وتغيّر الجلسة أثناء العمليات. اختبارات صلاحيات Firestore تتطلب المحاكي؛ راجع [تشغيلها](docs/firestore-rules-tests.md).
