BLACKBOX / دليل المتعلم

دليل ملفات التدريب والتحليل

تدرّب على قراءة الأدلة، ثم اكتب ما توصلت إليه. تجمع الحزمة ملفات اصطناعية للسجلات والإعدادات والويب والبريد، مع قارئ يعمل على جهازك باستخدام Python 3.

تنزيل ملفات التدريب (ZIP) كيف أبدأ؟ ↓

حلّل سجلات المصادقة من الهاتف داخل BLACKBOX. افتح مرحلة السجلات لاستخدام القارئ مع البحث والتصفية وتحديد القرائن. ولتشغيل أدوات الحزمة محليًا، استخدم حاسوبًا يعمل بنظام Windows أو Linux أو macOS مع Python 3. بعد تنزيل الحزمة يمكنك تشغيل أدواتها دون اتصال بالشبكة أو آلة افتراضية.

البدء اختر تمرينك توثيق العمل ومراجعته عن القارئ والملفات

خطوات التجهيز

ابدأ بثلاث خطوات

  1. نزّل الحزمة

    استخدم زر «تنزيل ملفات التدريب» للحصول على ملف blackbox-defense-kit.zip. الحزمة نفسها تخدم التمارين الأربعة.

  2. استخرج الملفات كاملةً

    فكّ ضغط ZIP، ثم افتح مجلد blackbox-defense. ستجد داخله analyze.py وملفات الأدلة ودليلًا نصيًا يمكنك الاحتفاظ به للقراءة دون اتصال.

  3. افتح الطرفية داخل المجلد

    تحقّق من وجود Python 3 على جهازك، ثم اعرض مساعدة القارئ بالأمر المناسب لنظامك:

    Linux وmacOS

    python3 analyze.py --help

    Windows

    py -3 analyze.py --help

    تعتمد بقية الأمثلة على python3. في Windows يمكنك استبداله بـ py -3 أو python إذا كان تثبيتك يشغّل Python 3 بهذا الاسم.

ابدأ بقراءة الملف الأصلي وتحديد سؤال التحقيق. استخدم القارئ للتحقق من ملاحظاتك، ثم دوّن الدليل والاستنتاج داخل مرحلة التدريب المناسبة.

01

تحليل سجلات المصادقة

اربط الوقت بالجلسة والمصدر والجهاز.

يمكنك قراءة السجلات والبحث فيها وتحديد القرائن مباشرةً داخل صفحة المرحلة، من الهاتف أو الحاسوب، ثم إضافتها إلى نتائجك.

ملف الدليل

auth-events.csv

أمر التحليل

python3 analyze.py logs

ما الذي توثّقه؟

خطًا زمنيًا ومذكرة فرز تفصل الوقائع عن الاستنتاجات. احسب عدد الأحداث والجلسات من الملف بنفسك، ثم قارنه بمخرجات القارئ.

وثّق عملك ثم راجعه

نفّذ مراحل المسار بالتتابع: اقرأ الدليل، استخرج ملاحظاتك، ثم سجّل الاستنتاج والقرينة والحدود والخطوة التالية داخل BLACKBOX. تشغيل القارئ يعرض الوقائع؛ تؤكّد إنجاز المرحلة يدويًا بعد تنفيذ بنودها.

عن القارئ والملفات

قراءة محلية للأدلة

يستخدم القارئ مكتبات Python القياسية لقراءة ملفات الحزمة دون تعديلها أو تنفيذ محتواها. يعيد رمز خروج غير صفري عند ملف مفقود أو صيغة غير صالحة. يبحث عن الأدلة بجوار السكربت، ويمكن تشغيله من مجلد آخر بتحديد مسار analyze.py.

عينات للتعلّم

البيانات اصطناعية، وتخلو العينات من كلمات مرور حقيقية أو مرفقات تنفيذية. روابط البريد مكتوبة بصيغة hxxps ويمكن إتمام التمرين بقراءتها كنص. نتائج القارئ تخص الملفات المعطاة؛ فهي لا تمثل فحصًا لجهازك أو شبكتك، أو قرار احتواء، أو درجة موثقة.

بصمات الملفات

يسرد ملف SHA256SUMS بصمات الملفات الموزعة. تطابق SHA-256 يثبت تطابق البايتات مع مرجع الحزمة؛ توثيق أصالة المصدر أو سلامة الملف يحتاج تحققًا إضافيًا.

اختياري: حفظ المخرجات بصيغة JSON

أضف --json للحصول على مخرجات منظمة. المثال التالي ينشئ ملفًا جديدًا باسم observations.json في المجلد الحالي بواسطة إعادة توجيه المخرجات:

python3 analyze.py logs --json > observations.json

قارئ الأدلة نفسه يبقى للقراءة فقط؛ الملف الجديد هو المخرج الذي اخترت حفظه.
