HOW IT WORKS

كيف تنشئ مختبرك؟

اتبع هذه الخطوات بالترتيب. يمكنك فتح شرح كل خطوة قبل الانتقال إلى التدريب. لا يمكن تجاوز أي خطوة في معالج الإعداد دون تأكيد تنفيذها.

01جهّز جهاز Windows

تأكد من توفر مساحة تخزين وذاكرة كافيتين، ومن تفعيل دعم المحاكاة الافتراضية. احتفظ بنسخة احتياطية من الملفات المهمة.

02ثبّت VirtualBox

ثبّت VirtualBox من المصدر الرسمي، ثم أنشئ آلة افتراضية جديدة أو استورد آلة Kali الموجودة لديك.

03شغّل Kali Linux

أقلع Kali داخل VirtualBox، وتأكد من عمل النظام، ثم أنشئ Snapshot قبل أي تجربة عملية.

04اعزل شبكة المختبر

استخدم Host-only عند الحاجة للتواصل مع Windows، أو Internal Network لعزل الآلات عن المضيف. لا تستخدم Bridged للأهداف الضعيفة دون ضرورة وضوابط واضحة.

05اختر مسار التدريب

افتح «مسارات التدريب» في لوحة BLACKBOX، واختر المجال ثم المرحلة المتاحة واتبع تعليماتها على الأنظمة المصرح بها.

06وثّق واحفظ نتائجك

سجّل الأدلة والملاحظات، وراجع سجل المختبر، ثم نزّل نسخة احتياطية من صفحة «النسخ والتقارير».

التكامل مع Kali Linux

نعمل على تجهيز ربط آمن بين BLACKBOX وKali داخل VirtualBox لتنفيذ مهام تدريبية مصرح بها واستيراد نتائجها. الربط المباشر لم يُفعّل بعد.

Windows HostKali / VirtualBox● غير متصل

خطوات التجهيز الآمن

  1. شغّل Kali داخل VirtualBox وتأكد من وجود Snapshot.
  2. استخدم شبكة Host-only لاتصال Windows بالآلة الافتراضية دون تعريض المختبر للإنترنت.
  3. حدد الآلات المسموح اختبارها. لا تفتح SSH أو API على الإنترنت.
  4. الخطوة التالية هي تثبيت وكيل محلي موثوق والتحقق من الصلاحيات قبل أي تنفيذ.

هذه تعليمات تجهيز فقط. الموقع لا يتصل بـKali حالياً ولا ينفذ أوامر على جهازك.
