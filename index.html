WELCOME TO BLACKBOX LAB

تعلّم الأمن السيبراني بالتطبيق، لا بالحفظ فقط.

BLACKBOX مساحة عربية لتنظيم تدريبك داخل مختبر آمن. اختر مساراً، نفّذ الخطوات على أجهزتك الافتراضية، سجّل الأدلة والملاحظات، وتابع تقدّمك. الموقع لا ينفذ الأوامر على جهازك تلقائياً.

المسار يجمع مهارة مثل تحليل الشبكات، والمرحلة مهمة صغيرة ذات خطوات ونتائج. أكمل المراحل بالتتابع.
تُحفظ بيانات الضيف في متصفحك. يمكنك تنزيل نسخة احتياطية أو تسجيل الدخول لمزامنة تقدم الحساب عندما تكون الخدمة متاحة.
لتجربة الأدوات على آلات تملكها أو لديك تصريح باختبارها، دون تعريض شبكتك الفعلية أو الآخرين للخطر.
KALI LINUX / LOCAL LAB

تجهيز الربط مع Kali Linux

حالة الاتصال: غير متصل — الربط المباشر لم يُفعّل بعد. يمكنك الآن تجهيز المختبر بأمان؛ تشغيل الأوامر وقراءة حالة Kali من الموقع يتطلبان تطبيقاً محلياً منفصلاً.

  1. شغّل Kali Linux داخل VirtualBox على جهازك الشخصي.
  2. استخدم شبكة Host-only أو Internal Network بحسب حاجة المختبر، ولا تعرض آلة ضعيفة على شبكة Bridged عامة.
  3. أنشئ لقطة Snapshot قبل التجارب، وحدّد الآلات المسموح باختبارها.
  4. بعد تطوير وكيل BLACKBOX المحلي والتحقق من هويته وصلاحياته، يمكن إضافة فحص حالة Kali وتبادل نتائج التدريب بموافقتك.

تنبيه: هذه تعليمات إعداد فقط، وليست اتصالاً حقيقياً. لا تفتح SSH أو API للعامة، ولا تُدخل كلمات مرور Kali داخل الموقع.
