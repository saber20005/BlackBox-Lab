# Suite learning pathways v1

The public curriculum at `?view=journeys` mirrors CyberTrace's four pathway IDs and 16 ordered steps. Steps alternate between existing CyberTrace cases and BLACKBOX tracks. This is a **read-only navigation aid**; it does not alter progress keys, enrollment, account linkage, Firestore rules, grades or certificates.

BLACKBOX displays a local completed marker only if its existing account-scoped state already marks every stage in the referenced track complete. Cross-site completion is unknown: never infer it from a click, email match, XP, or prior synced receipt. No credentials or identifiers appear in partner links.

Release checks: run existing quality and browser suites, inspect RTL mobile widths 360/390 px, test account changes/guest state, compare version and every pathway step with CyberTrace, and merge only after checks. Do not manually trigger Vercel deployments during the quota limit.
