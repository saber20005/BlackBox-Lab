# أدوات التدريب داخل BLACKBOX

أُنجزت هذه الدفعة على أربع خطوات متتابعة، مع فحص كل خطوة قبل التالية. لا تضيف مراحل أو نقاطًا أو حقولًا جديدة إلى مستند التقدم في Firebase.

## 1. قارئ سجلات المصادقة

يتوفر داخل مراحل مسار `logs` على الهاتف والحاسوب. يقرأ ملف `auth-events.csv` الاصطناعي نفسه المرفق بالحزمة، مع البحث والتصفية وترقيم السطور الأصلية. يحدد المتعلم قرائن ثم يضيفها إلى حقل نتائج المرحلة؛ تبقى الملاحظات والنتائج السابقة محفوظة عبر مسار الحفظ القائم. اختيار القرائن لا يؤكد إكمال المرحلة.

القارئ لا يرفع ملفات ولا يفحص الجهاز. يدعم CSV مقتبسًا وترقيم السطور الفعلية، ويرفض الصيغة غير الصالحة والملفات التي تتجاوز 64KiB أو 500 حدث. تُعرض القيم كنصوص، وتُلغى القراءة عند استبدال التمرين. يُعاد ضبط الاختيار عند تبدل المرحلة أو الحساب.

## 2. التلميحات والمراجعة

لكل مرحلة من المراحل الثلاثين تلميح عام وتوجيه أدق ومراجعة بعد المحاولة. لا يدخل نص المراجعة إلى الصفحة قبل طلبه صراحةً بعد كتابة ملاحظة أو نتيجة فعلية؛ القالب الفارغ لا يعد محاولة. تبقى حالة إظهار التلميحات مؤقتة، ولا تغير الإنجاز أو الدرجات. يبدأ عرض جديد عند تبدل المرحلة أو الحساب.

## 3. المهام وبصمة المهارات

تعرض `mission-mode.html` آخر تقدم محفوظ في الحساب بعد استعادة جلسة الدخول، أو تقدم الضيف عندما تؤكد الخدمة عدم وجود مستخدم مسجل. يوضح شريط الحالة المصدر وحالة التحديث. عند تعذر قراءة الحساب تُستخدم نسخة لذلك الحساب فقط إن توفرت، مع تمييز المسودة المحلية غير المتزامنة. لا تستبدل بيانات الضيف بيانات حساب تعذر تحميله.

القراءة المستقلة في `progress-session.js` لا ترفع المسودات ولا تعدل أو تحذف ذاكرة التقدم. تُرفض الاستجابات المتأخرة بعد تبديل المستخدم، وتُمسح بيانات المالك السابق من العرض أثناء استعادة المالك الجديد. لعرض تعديل حديث، أكمل مزامنته في الصفحة الرئيسية ثم استخدم «تحديث عرض التقدم».

## 4. ملف أعمال مختار وPDF

من «النسخ والتقارير» أو صفحة المهام، افتح `portfolio.html`. اختر المراحل المكتملة التي تريد عرضها ثم راجع المعاينة. لا تُختار مراحل افتراضيًا، وتبقى الملاحظات والنتائج مستبعدة حتى تفعّل كل خيار بنفسك. تظل نصوص المراحل غير المختارة خارج التقرير.

زر «طباعة / حفظ PDF» يفتح نافذة طباعة المتصفح؛ اختر وجهة «حفظ بتنسيق PDF» إذا كانت متاحة على جهازك. يستخدم الإخراج تنسيق A4 واتجاه RTL، ويستبعد أدوات التحكم من الطباعة. ليس تنزيلًا تلقائيًا عبر خادم ولا رفعًا إلى LinkedIn. يحتوي التقرير وصف التأكيد اليدوي ومصدر النسخة المعروضة، ويستبعد هوية الحساب وبريده ومعرفه وسجل النشاط وحالات الأجهزة.

عند تبديل الحساب تُمسح المعاينة والاختيارات وخيارات مشاركة النصوص مباشرةً. تبقى النصوص المختارة كاملةً دون اقتطاع صامت؛ راجعها قبل مشاركة الملف.

## التحقق

- اختبارات CSV والقرائن، ونماذج التلميحات، والقارئ الخاص بالحساب، ونموذج ملف الأعمال تعمل ضمن اختبارات Node القائمة.
- فحص المتصفح يختبر البحث والتصفية والإضافة دون فقد المسودة أو منح إكمال، والتلميحات بعد المحاولة، وعزل الحسابات والاستجابات المتأخرة، والمحافظة على المسودات المحلية دون رفعها.
- يُولَّد PDF فعلي في Chromium، ثم يستخرج `pdftotext` نصه للتحقق من استبعاد النصوص الخاصة افتراضيًا وتضمين النصوص المختارة صراحةً فقط.
- جميع بيانات الاختبارات اصطناعية والخدمات محلية؛ النجاح لا يثبت وصول قراءة أو كتابة إلى حساب إنتاجي بعينه.
