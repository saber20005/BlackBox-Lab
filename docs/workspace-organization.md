# تنظيم مساحة التدريب

كانت الرئيسية تعرض المسارات العشرة والإعلانات والإحصاءات والخطة وحالة البيئة وأدوات الحفظ معًا، وكانت موارد ZIP تسبق شرح المهمة. أصبحت واجهة التدريب تركّز على الخطوة الحالية، مع بقاء الأدوات والروابط القديمة متاحة.

## الأقسام الأربعة

| القسم الرئيسي | المحتوى | الروابط الثانوية المحفوظة |
| --- | --- | --- |
| تدريبي | متابعة التدريب، ملخص تقدم صغير، اقتراح جلسة واحد | `?view=home` |
| المسارات | البحث في المهارات واختيار مرحلة متاحة | `?view=tracks` وروابط `track` و`stage` |
| تقدّمي | نظرة عامة، المهام والمهارات، ملف الأعمال | `?view=progress` و`plan` و`journal` و`skills`، وصفحتا المهام وملف الأعمال |
| حسابي | إدارة الحساب والحفظ والنسخ ومساعدة المختبر | `?view=account` و`backups` و`troubleshoot` |

تستخدم صفحات المهام وملف الأعمال الإطار والتنقل نفسيهما. مصدر إنجازات CyberTrace يظل مستقلًا عن تأكيد مراحل BLACKBOX؛ تنظيم التنقل لا يغيّر احتساب التقدم أو مصدره.

## ترتيب التمرين

1. هدف المرحلة وشرح المطلوب.
2. الأدلة: قارئ سجلات ظاهر في مسار السجلات، وملفات وأوامر قابلة للفتح لبقية المسارات.
3. كتابة النتائج والملاحظات مع الحفظ القائم.
4. مراجعة بنود التحقق ثم تأكيد الإكمال.

تبدأ التلميحات وموارد التحليل المحلي مطوية. فتحها وإغلاقها لا يستبدل حقول الإجابة أو اختيار القرائن أو حالة التلميحات. يبقى القسم المفتوح وتركيز لوحة المفاتيح محفوظين أثناء تحديث الحساب نفسه؛ ويعود الطي الافتراضي عند تغيير الصفحة أو المرحلة أو الحساب. في مسار السجلات، تبقى Python والحزمة المحلية خيارًا إضافيًا للقارئ داخل المتصفح. الملفات والأوامر الخاصة بالمختبرات الأخرى تبقى متاحة بوضوح ضمن الخطوة الثانية.

تبدأ صفحة التعريف بزر تدريب من المتصفح، وتبقى إرشادات VirtualBox ومعالج الإعداد داخل قسم اختياري قابل للفتح. يُفتح التدريب من الروابط المباشرة للزائر الجديد دون اشتراط المرور بصفحة التعريف.

## أدوات ومساعدة

تحتوي القائمة الصغيرة في الترويسة على الحساب والتنزيل السريع ودليل الميزات وروابط المساعدة. لا يظهر إعلان دائم فوق كل تمرين. تبقى إدارة الحساب متاحة مباشرةً من «حسابي» أيضًا. تُغلق قائمة الأدوات عند الانتقال داخل مساحة العمل؛ وتبقى مفتوحة خلف النوافذ الحوارية لتعود لوحة المفاتيح إلى زر ظاهر عند الإغلاق.

## حدود التغيير والتحقق

لم تتغير إعدادات Firebase أو App Check أو قواعد Firestore أو مخطط التقدم أو طبقة المزامنة أو التقييم. تأكيد المراحل يدوي، والتقرير ليس شهادة. تستمر خيارات خصوصية PDF والتسمية الصريحة لمصدر الحساب أو الضيف أو النسخة المحلية.

يغطي فحص المتصفح التنقل بالأقسام الأربعة والروابط القديمة وعودة المتصفح، وعروض320/390/1440px، وترتيب المهمة، والتفاصيل القابلة للفتح بلوحة المفاتيح، وحفظ المسودة عند المغادرة أثناء تأخير الحفظ، وعزل الحسابات والردود المتأخرة، وPDF فعليًا مع استخراج النص للتحقق من الخصوصية. تبقى فحوص التحميل السابقة جزءًا من الاختبارات.
