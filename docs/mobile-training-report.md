# تقرير التدريب الملائم للهاتف
السبب: زر "تنزيل تقرير Markdown" كان يحفظ ملف .md خامًا، وبعض عارضي الملفات على Android يعرضون رموز Markdown دون تنسيق. أسطر التواريخ الإنجليزية/العربية تختلط بصريًا وتبدو النتائج والملاحظات غير مفهومة.

## التغيير
- الافتراضي الآن تقرير HTML ذاتي الاحتواء، بدون أي موارد أو اتصالات خارجية. تصميم RTL عربي وترويسات واضحة وملخص تقدم وحالات بيئة **يدوية** وبطاقات مسارات ومراحل قابلة للفتح وبنود تحقق.
- المحتوى النصي المحفوظ يظهر كما كُتب مع التفاف الأسطر والعزل ثنائي الاتجاه؛ تسلسل الأرقام وNmap وأوامر المختبر يظل قابلًا للقراءة على الهاتف.
- زر داخلي للطباعة / الحفظ بصيغة PDF عبر واجهة طباعة المتصفح؛ التقارير تُولّد على جهاز المستخدم فقط. أزرار Markdown السابقة ما زالت متاحة ولكنها اختيارية.
- لا تعديل في JSON Backup، Firebase/Auth/Firestore، الملاحظات، الاستعادة، نقاط التدريب أو نتائج المستخدم.
- تنبيه لخصوصية التقرير ومحدودية التوثيق؛ البيئة أدخلها المستخدم يدويًا، وكون المرحلة "مكتملة" ليس حكمًا خادميًا موثّقًا.

## ضمان الأمان
HTML escape لجميع الحقول من المستخدم ومحتوى المسارات، مع CSP تمنع تحميل موارد خارجية، ونظام طباعة يكشف جميع المراحل مؤقتًا ويعيد حالة الطي. التقارير المصدرة تحتوي معلومات خاصة بالمستخدم؛ لا ترفع أو ترسل تلقائيًا.
